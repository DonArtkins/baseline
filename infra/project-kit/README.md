# Infra project kit

This kit owns environments, build/release delivery and recovery. Start with the [tracker](context/progress-tracker.md), then the current spec and its named context. The six base context files are architecture, stack-contract, integration-contracts, code-standards, test-strategy and progress-tracker. Specialist context adds environment and deployment-targets.

Use numbered feature specs for real project outcomes. The initial planning-foundation spec is a fillable starter, not a delivered feature. Read root templates and examples before expanding it.
