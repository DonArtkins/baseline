# Research workspace

Use this folder to establish what is known before deciding what to build. Separate original sources, your interpretation, verified findings and project decisions.

| Location | Purpose |
|---|---|
| [project brief](project-brief.md) | User problem, constraints and success measures |
| [open questions](open-questions.md) | Unknowns with owners and blocking status |
| [source register](sources/REGISTER.md) | Attribution, access status and evidence quality |
| `sources/` | Authorized source notes or sanitized local material |
| `findings/` | Focused answers with alternatives and evidence |
| [knowledge-base](knowledge-base/README.md) | How to create and maintain your own reusable knowledge |

For each research task, state the decision it will inform. Prefer small answers linked to sources over a generic encyclopedia. Record version/date for changeable claims. Use project ADRs to promote findings into binding decisions.
