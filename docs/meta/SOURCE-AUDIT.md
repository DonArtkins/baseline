# Template provenance and scope of review

Prepared 2026-09-27 from read-only local references and public documentation.

## Griot reference

Inventoried 2,267 files, including ignored workflow evidence, and indexed workflow-document headings across root and all seven system kits. Across Griot and the knowledge reference, the structural index covered 613 Markdown documents and 149,364 lines. This is a structural scan, not a claim that every application implementation line was reviewed.

Read the root and system organization, selected agent guidance, shared skills, context structures, representative feature specs, document-ownership rules, contract/branch/secret gates, Husky hooks, inspiration catalog and master design-system pattern. Reviewed the bootcamp contract's extracted opening/stack material outside the source tree. Inspected the organization of bugs and review intake without copying their evidence into this template.

Adopted: per-system kits, explicit ownership, plan-before-code, schema/UI approval, contract sync, trackers before push, regression evidence, review intake and local/CI gates. Generalized the technology choices and removed delivery history, private data, product names, routes and domain-specific rules.

## Private knowledge reference

Inspected its file organization, agent routing, contribution policy, master index, representative volume outlines and update conventions. Adopted only the general ideas of topic-based retrieval, cross-cutting versus domain guidance, provenance and maintained corrections. No proprietary volumes, company policies, original prose or datasets were copied.

## Public links

The [source register](../../research/sources/REGISTER.md) records access limits. The YouTube transcript, Instagram reel content and X posts were not available. Their contents were not invented. The six core context names in baseline are an adaptation, not a verified transcription of the video's exact list.

Tool configuration was checked against [Husky](https://typicode.github.io/husky/get-started.html), [CodeRabbit](https://docs.coderabbit.ai/reference/configuration), [GitHub's secure-use reference](https://docs.github.com/en/actions/reference/security/secure-use) and [Context7's official repository](https://github.com/upstash/context7). Context7 itself was not configured in the session; an attempted public documentation lookup did not return usable content.

## Deliberate improvements

Keep current state in one owner document; do not carry historical banners into every AGENTS file. Separate template validation from product verification. Inspect the staged snapshot rather than unstaged files during commit checks. Treat contract declarations as review evidence, not automatic semantic proof. Make optional systems explicit and preserve unavailable sources as research leads.
