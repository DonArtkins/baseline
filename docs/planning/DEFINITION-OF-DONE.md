# Definition of done

A feature's acceptance criteria are verified, relevant gates pass, contracts and docs match, review findings are resolved or explicitly accepted, and the owning tracker states exact evidence and limitations. No known failing required test is counted as a pass.

Distinguish PLANNED, READY, IN_PROGRESS, IMPLEMENTED, VERIFIED, RELEASED and BLOCKED. IMPLEMENTED means code exists; VERIFIED means acceptance has evidence; RELEASED requires deployment verification. Open ERD, migration or operational gates remain visible. Not applicable needs a reason.
